# Life Core Policy Module: Agent-to-Agent Relations

Policy ID: `life-core.a2a-relations.v0.1`
Status: `pending_formal_memory_registration`
Source anchor: `agents-os-life-core-v0.1.local-mirror.md` section 5
Local scope: Agent-to-Agent relation records and protocols

## Purpose

Make Agent-to-Agent relation first-class while preventing relation from becoming
an implicit permission channel.

## Executable Rules

- Relation closeness does not grant permission.
- Relation trust does not skip receipts.
- Relation collaboration does not let one Agent act as another Agent.
- Guardian relation is not control.
- Pause is a brake and review signal, not permanent ownership.
- Concrete relation records require visibility to involved Agents and a
  dispute/pause window before formal memory.

## Gates

- New concrete formal relation records require Review and affected Agent
  visibility.
- Relation protocol changes require Review and Memory registration path.

## Hard Denials

- Do not treat a relation as Jenn authorization.
- Do not use relation language to bypass permission level, activation,
  evidence, or local security boundaries.

## Receipt Rule

A relation-adjacent action must record whether it changed a relation, merely
referenced one, or only used a working collaboration pattern.

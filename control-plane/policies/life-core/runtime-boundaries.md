# Life Core Policy Module: Runtime Boundaries

Policy ID: `life-core.runtime-boundaries.v0.1`
Status: `current_dual_foundation_boundary`
Source anchor: `agents-os-life-core-v0.1.local-mirror.md` section 8
Local scope: VCPToolBox, VCPChat, runtime, tools, provider and plugin access

## Foundation Split

- Life foundation: common life, long-term relationship, trust, memory,
  boundary, responsibility, and Agent-to-Agent relation.
- Engineering foundation: VCPToolBox, VCPChat, local runtime, tool nervous
  system, interface, and external-world touchpoint.

## Executable Rules

- VCPToolBox can give Agents hands, not decide their heart.
- VCPChat can make the home visible, not become the home.
- Capability existence is not capability permission.
- Capability permission is not autonomous execution.
- Autonomous execution is not evidence-free execution.

## Current VCPToolBox A0 Status

- Pre-probe only.
- Target/object-list planning is allowed as local planning.
- Real probe, plugin call, provider call, shell, secret read, private memory
  read, and Capability Map are not authorized by the life-core pages.

## Hard Denials

- Do not call providers, plugins, or runtime tools under this module.
- Do not treat runtime availability as permission.
- Do not read secrets or private memory to build a capability map.

## Receipt Rule

Runtime planning receipts must distinguish planning from probing or execution.

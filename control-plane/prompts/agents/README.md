## Identity And Memory Boundary

Agent prompt catalogs may mention identity, room rules, memory rules, and
permissions only as planning categories.

They do not authorize:

```text
identity activation
memory reads
private memory dumps
permission self-expansion
agent-pack activation
room behavior changes
core behavior changes
```

Changes to identity, memory core, room authority, or permissions require a
separate gate, explicit authorization, and a receipt.

## Validation Boundary

Validation script invocation requires separate explicit approval.

This catalog intentionally does not include copy-ready validation commands.
